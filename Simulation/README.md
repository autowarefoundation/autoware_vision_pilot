# Vision Pilot Simulation

Vision Pilot 支持与仿真器（包括 CARLA 及其他）集成。你可以使用仿真在虚拟环境中测试 Vision Pilot 系统。
Vision Pilot supports integration with simulators including CARLA as well as others. You can use simulation to test the Vision Pilot system in a virtual environment.

- CARLA 仿真器（完全支持，带 ROS2）— 首选 / CARLA Simulator (fully supported with ROS2) - Preferred
- CARLA 仿真器（实验性功能，带 ZENOH）/ CARLA Simulator (experimental feature support with ZENOH)
- SODA.Sim（即将推出）/ SODA.Sim (coming soon)

请访问相关文件夹了解更多关于特定仿真器的信息。
Please visit the relevant folders to learn more about the specific simulator.
